Regenerated for hctsa v3.0.0 (October 2026) with
matlab.codetools.requiredFilesAndProducts (MATLAB R2026a), run on each
operation function named in FeatureSets/INP_mops_hctsa.txt (the registered
operations) and listing the toolbox products it reports. This is static
analysis of the call graph, so a function is listed if any code path might
need a toolbox, even if that path is not used by a registered operation.
Notes:
  * CO_PartialAutoCorr needs the Econometrics Toolbox (parcorr) only for the
    optional 'ols' method; the registered operations use 'burg' only.
  * PP_Compare needs the Financial Toolbox (boxcox) only for the optional
    'boxcox' method, which no registered operation uses.
  * The System Identification Toolbox is no longer required.
  * Operations that need the Econometrics Toolbox otherwise: SY_VarRatioTest,
    SY_PPtest, SY_KPSStest and the Ljung-Box test in HT_IndependenceTests.
The lists of provided (external) toolboxes further down were compiled from
the calls the code makes into each toolbox, not from this analysis.
Any modifications to toolbox dependencies would be appreciated.
